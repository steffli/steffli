### About me

I'm a biologist and bioinformatician who kept following the data: from the lab bench to Python scripts, from research servers to an OpenStack cloud, and now into systems programming at **42 Heilbronn**.

I want to help organisations move their processes onto cloud infrastructure they can trust, especially where **life sciences meet technology**.

- 🧫 **Background:** B.Sc. and M.Sc. in Biology / Bioinformatics, University of Tübingen
- 🔬 **Lab habit:** strict SOPs and documented steps, because reproducible work matters, in the lab and in software
- ☁️ **Now:** C++ and systems programming, Linux server administration, and OpenStack
- 📚 **Learning:** GxP, GAMP 5 and computer system validation
